## 🚀 自動清理腳本

創建 `cleanup.ps1` (PowerShell):

```powershell
# 發布前清理腳本

Write-Host "開始清理 repository..." -ForegroundColor Green

# 1. 刪除測試腳本
Write-Host "`n清理測試腳本..." -ForegroundColor Yellow
$testScripts = @(
    "apply-migration.js",
    "check-accounts.js",
    "check-accounts.ts",
    "check-company-12345.js",
    "check-reconciliation.js",
    "check-tx-status.js",
    "inspect_excel.js",
    "inspect_excel_v2.js",
    "simulate-automatch.js",
    "test-automatch.js"
)

foreach ($file in $testScripts) {
    if (Test-Path $file) {
        Remove-Item $file -Force
        Write-Host "  ✓ 已刪除: $file" -ForegroundColor Gray
    }
}

# 2. 刪除測試輸出
Write-Host "`n清理測試輸出..." -ForegroundColor Yellow
$outputFiles = @(
    "check-output.txt",
    "simulate-output.txt",
    "test-output.txt"
)

foreach ($file in $outputFiles) {
    if (Test-Path $file) {
        Remove-Item $file -Force
        Write-Host "  ✓ 已刪除: $file" -ForegroundColor Gray
    }
}

# 3. 刪除測試資料
Write-Host "`n清理測試資料..." -ForegroundColor Yellow
$testData = @(
    "0000109506251445.csv",
    "Invoice_123123123.pdf",
    "Invoice_33333.pdf",
    "報價單_請款單模板.xlsx",
    "luk-high-resolution-logo-transparent.png",
    "luk-high-resolution-logo.png"
)

foreach ($file in $testData) {
    if (Test-Path $file) {
        Remove-Item $file -Force
        Write-Host "  ✓ 已刪除: $file" -ForegroundColor Gray
    }
}

# 4. 刪除資料庫
Write-Host "`n清理資料庫..." -ForegroundColor Yellow
if (Test-Path "prisma/dev.db") {
    Remove-Item "prisma/dev.db" -Force
    Write-Host "  ✓ 已刪除: prisma/dev.db" -ForegroundColor Gray
}
if (Test-Path "prisma/dev.db-journal") {
    Remove-Item "prisma/dev.db-journal" -Force
    Write-Host "  ✓ 已刪除: prisma/dev.db-journal" -ForegroundColor Gray
}

# 5. 刪除建置產物
Write-Host "`n清理建置產物..." -ForegroundColor Yellow
if (Test-Path "tsconfig.tsbuildinfo") {
    Remove-Item "tsconfig.tsbuildinfo" -Force
    Write-Host "  ✓ 已刪除: tsconfig.tsbuildinfo" -ForegroundColor Gray
}
if (Test-Path ".next") {
    Remove-Item ".next" -Recurse -Force
    Write-Host "  ✓ 已刪除: .next/" -ForegroundColor Gray
}

# 6. 刪除 AI 助手目錄 (可選)
Write-Host "`n清理 AI 助手目錄..." -ForegroundColor Yellow
$aiDirs = @(".agent", ".claude", ".gemini", "claude")
foreach ($dir in $aiDirs) {
    if (Test-Path $dir) {
        Remove-Item $dir -Recurse -Force
        Write-Host "  ✓ 已刪除: $dir/" -ForegroundColor Gray
    }
}

$aiFiles = @("CLAUDE.md", "gemini.md")
foreach ($file in $aiFiles) {
    if (Test-Path $file) {
        Remove-Item $file -Force
        Write-Host "  ✓ 已刪除: $file" -ForegroundColor Gray
    }
}

# 7. 刪除臨時文件
Write-Host "`n清理臨時文件..." -ForegroundColor Yellow
$tempFiles = @(
    "update-terminology.ps1",
    "初始需求.md",
    "實作總結-自動對帳.md"
)

foreach ($file in $tempFiles) {
    if (Test-Path $file) {
        Remove-Item $file -Force
        Write-Host "  ✓ 已刪除: $file" -ForegroundColor Gray
    }
}

Write-Host "`n✅ 清理完成！" -ForegroundColor Green
Write-Host "`n請檢查以下項目：" -ForegroundColor Cyan
Write-Host "  1. 更新 README.md" -ForegroundColor White
Write-Host "  2. 檢查 .env 檔案" -ForegroundColor White
Write-Host "  3. 檢查 .gitignore" -ForegroundColor White
Write-Host "  4. 執行測試確認功能正常" -ForegroundColor White
Write-Host "  5. 提交變更到 Git" -ForegroundColor White
```

## ⚠️ 注意事項

1. **備份重要檔案**: 清理前先備份可能需要的檔案
2. **測試功能**: 清理後執行完整測試
3. **檢查 Git**: 確認沒有誤刪重要檔案
4. **環境變數**: 確保 .env.example 包含所有必要變數
5. **文件更新**: 確保所有文件都是最新的
