### 3. 安全審計日誌系統 ✅

#### 3.1 安全事件追蹤
- **檔案**: `src/lib/security-audit.ts`
- **功能**:
  - 10 種安全事件類型:
    - `rate_limit_exceeded` - 速率限制超出
    - `csrf_validation_failed` - CSRF 驗證失敗
    - `invalid_input_detected` - 無效輸入檢測
    - `unauthorized_access_attempt` - 未授權訪問嘗試
    - `suspicious_file_upload` - 可疑檔案上傳
    - `sql_injection_attempt` - SQL 注入嘗試
    - `xss_attempt` - XSS 攻擊嘗試
    - `authentication_failed` - 認證失敗
    - `privilege_escalation_attempt` - 權限提升嘗試
    - `data_breach_attempt` - 資料洩露嘗試
  
  - 4 個嚴重性級別:
    - `low` - 低
    - `medium` - 中
    - `high` - 高
    - `critical` - 關鍵
  
  - 功能:
    - 事件記錄和儲存 (最近 1000 個)
    - 按類型/嚴重性/IP 篩選
    - 統計分析
    - IP 可疑活動檢測

#### 3.2 安全審計 API
- **檔案**: `src/app/api/security/audit/route.ts`
- **端點**: `GET /api/security/audit`
- **功能**:

## 安全工具函數

### CSRF 保護
```typescript
import { getCsrfToken, verifyCsrfToken, createCsrfFetchOptions } from '@/lib/csrf';

// 獲取 Token
const token = await getCsrfToken();

// 驗證 Token
const isValid = await verifyCsrfToken(headerToken);

// 創建帶 Token 的 fetch 選項
const options = createCsrfFetchOptions({ method: 'POST' });
```

### 輸入清理
```typescript
import { 
    sanitizeInput, 
    escapeHtml, 
    sanitizeFilename,
    isValidEmail,
    isValidUrl,
    sanitizeNumber,
    hasNoSqlInjection 
} from '@/lib/sanitize';

// 清理一般輸入
const clean = sanitizeInput(userInput, {
    stripHtml: true,
    maxLength: 1000,
    escapeHtml: true
});

// 清理檔案名稱
const filename = sanitizeFilename(uploadedFilename);

// 驗證 Email
if (isValidEmail(email)) { /* ... */ }

// 檢測 NoSQL 注入
if (hasNoSqlInjection(queryObject)) { /* 阻擋請求 */ }
```

### 安全審計
```typescript
import { logSecurityEvent, logCriticalSecurityEvent } from '@/lib/security-audit';

// 記錄安全事件
logSecurityEvent('xss_attempt', 'high', {
    ip: request.ip,
    action: 'comment_submission',
    input: suspiciousInput
});

// 記錄關鍵事件
logCriticalSecurityEvent('data_breach_attempt', {
    ip: request.ip,
    targetData: 'user_credentials'
});
```

## 使用方式

### 查看安全審計
1. 進入「設定」頁面
2. 點擊「安全審計」標籤
3. 查看即時安全事件和統計

### 檢查安全事件
```bash
# 獲取所有事件
curl http://localhost:3001/api/security/audit

# 獲取統計
curl http://localhost:3001/api/security/audit?stats=true

# 按類型篩選
curl http://localhost:3001/api/security/audit?type=rate_limit_exceeded

# 檢查 IP
curl http://localhost:3001/api/security/audit?ip=192.168.1.1
```

### 獲取 CSRF Token
```bash
curl http://localhost:3001/api/csrf-token
```
