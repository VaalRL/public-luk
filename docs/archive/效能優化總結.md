## API 端點總覽

| 端點 | 方法 | 功能 |
|------|------|------|
| `/api/health` | GET | 系統健康檢查 |
| `/api/metrics` | GET | 效能指標 |
| `/api/errors` | GET | 錯誤列表和統計 |
| `/api/errors?stats=true` | GET | 僅獲取錯誤統計 |
| `/api/errors?id=xxx` | GET | 獲取特定錯誤詳情 |
| `/api/errors` | DELETE | 清除錯誤記錄 |

## 效能指標

### 監控項目
1. **回應時間**
   - 正常: < 1000ms
   - 慢請求: 1000-3000ms
   - 非常慢: > 3000ms

2. **記憶體使用**
   - Heap Used
   - Heap Total
   - RSS (Resident Set Size)
   - External

3. **錯誤率**
   - 總錯誤數
   - 按嚴重性分類
   - 過去 24 小時錯誤數

4. **系統健康**
   - 資料庫連線狀態
   - API 可用性
   - 系統運行時間

## 使用方式

### 查看系統監控
1. 進入「設定」頁面
2. 點擊「系統監控」標籤
3. 查看即時系統狀態和效能指標

### 檢查系統健康
```bash
curl http://localhost:3001/api/health
```

### 獲取效能指標
```bash
curl http://localhost:3001/api/metrics
```

### 查看錯誤統計
```bash
curl http://localhost:3001/api/errors?stats=true
```
