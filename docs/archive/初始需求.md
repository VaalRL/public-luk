
一個小公司內部對帳用工具


總共頁面
1. 首頁Dashboard：可看到逐月對帳結果
2. 設定頁
3. 立帳頁：發報價單
4. 對帳頁


累積後一次對帳
1. 進入立帳頁面，設定公司、金額、品項、含稅設定
2. 點擊產出
3. 系統產出報價單檔案，把這一筆明細記錄到立帳表
4. 手動發給客戶
5. 客戶陸續匯款，手動記錄客戶回覆的匯款帳號
6. 進入對帳頁面，上傳銀行明細
7. 系統會顯示目前累積未處理帳款，此處可以修改。點擊對帳，系統自動開始對帳
8. 系統顯示對帳結果頁面，列出對帳結果，以表格呈現，可以在此處刪除或修改結果，未處理完成的銀行餘額與帳的可以累積到下個月


對帳頁面含有
1. 尚未對帳：前次遺留下來的未對帳資料與銀行餘額
2. 上傳銀行明細按鈕：上傳檔案，選擇要使用哪個模板解析
3. 新增繳款人帳號：點擊後可選客戶公司，可輸入對方回報的帳號後五碼，可在一公司下輸入多筆，也可以在一筆帳號位於多公司下


對帳結果頁
1. 分成兩分頁，每一分頁都區分上下半部，第一分頁上半部顯示本月的立帳表表，其中標示對帳結果，下半部列出未被銷帳的資料，另一分頁上半顯示本月銀行明細表，
2. 匯出對帳結果按鈕


設定頁
1. 客戶名單：其中可以設定聯絡人、公司名稱、基本資料、被使用過的轉帳後五碼
2. 銀行明細定義：上傳銀行明細後，用介面定義那一欄或那一列是後五碼、帳戶餘額、轉帳金額，用於後續上傳檔案解析


對帳邏輯
1. 檢查本月銀行明細中總共有哪些後五碼
2. 計算出本月每個相同帳號進帳總額
3. 列出這些後五碼是屬於哪些公司(同樣後五碼可能出現在不同公司，同公司下也有可能有多組帳號)
4. 列出該月份該公司應收帳款總額(帳單日期由舊至新排列)
5. 兩者相減，算出還有哪些帳單未滿足，顯示結果
