## ✅ 5 分鐘快速測試

### 測試 1: 建立第一個客戶和發票 (2 分鐘)

1. **新增客戶**
   - 進入「設定」→「公司管理」
   - 點擊「新增公司」
   - 填寫:
     - 公司名稱: `測試科技`
     - 統一編號: `12345678`
   - 新增銀行帳號:
     - 帳號: `1234567890123`
     - 後五碼: `90123`
   - 儲存

2. **建立發票**
   - 進入「立帳」
   - 點擊「新增帳單」
   - 選擇剛建立的客戶
   - 新增項目:
     - 名稱: `測試服務`
     - 數量: `1`
     - 單價: `10000`
   - 儲存

3. **驗證**
   - ✅ 發票編號自動生成
   - ✅ 儀表板顯示未收款 10,500 元

---

### 測試 2: 上傳銀行明細並對帳 (2 分鐘)

1. **準備測試檔案**
   - 建立 Excel 檔案 `test-bank-statement.xlsx`
   - 內容:
     ```
     日期       | 摘要     | 存款   | 備註
     2025-12-01 | 轉帳收入 | 10500  | 90123
     ```

2. **上傳對帳**
   - 進入「對帳」
   - 上傳檔案
   - 點擊「自動銷帳」

3. **驗證**
   - ✅ 交易成功匹配
   - ✅ 發票狀態變為「已付款」
   - ✅ 儀表板未收款歸零

---

### 測試 3: 查看監控儀表板 (1 分鐘)

1. **系統監控**
   - 進入「設定」→「系統監控」
   - 查看健康狀態
   - 查看效能指標

2. **安全審計**
   - 進入「設定」→「安全審計」
   - 查看安全事件

3. **驗證**
   - ✅ 所有指標正常顯示
   - ✅ 無錯誤或警告

## 🐛 常見問題檢查

### 問題 1: 發票編號重複
```
測試步驟:
1. 建立發票 A
2. 刪除發票 A
3. 建立發票 B (相同日期、相同公司)

預期: 發票 B 的編號應該是下一個序號，不是重複
```

### 問題 2: 對帳匹配錯誤
```
測試步驟:
1. 建立兩張發票 (相同金額)
2. 上傳一筆交易 (該金額)
3. 執行自動對帳

預期: 應該匹配較早的發票 (FIFO)
```

### 問題 3: PDF 中文亂碼
```
測試步驟:
1. 建立包含中文的發票
2. 下載 PDF

預期: 中文正確顯示
```

### 問題 4: 記憶體洩漏
```
測試步驟:
1. 開啟系統監控
2. 執行多次對帳操作
3. 觀察記憶體使用量

預期: 記憶體使用量穩定，無持續增長
```
