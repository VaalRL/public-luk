# Spreadsheet Comparator 使用說明

## 🚀 首次啟動

1. 雙擊 `Spreadsheet Comparator.exe`
2. 等待約 5-10 秒（首次啟動會初始化資料庫）
3. 應用程式視窗將自動開啟

## 📁 資料儲存位置

您的所有資料都儲存在：
```
C:\Users\[您的使用者名稱]\AppData\Roaming\Spreadsheet Comparator\
```

包含：
- `spreadsheet-comparator.db` - 資料庫檔案（包含所有公司、發票、對帳記錄）

## 💾 備份資料

### 方法一：使用內建備份功能
1. 開啟應用程式
2. 進入「設定」→「資料備份與還原」
3. 點擊「匯出資料庫」
4. 選擇儲存位置

### 方法二：手動備份
直接複製資料庫檔案：
```
C:\Users\[您的使用者名稱]\AppData\Roaming\Spreadsheet Comparator\spreadsheet-comparator.db
```

## 🔄 還原資料

### 使用內建還原功能
1. 進入「設定」→「資料備份與還原」
2. 點擊「匯入資料庫」
3. 選擇之前備份的 `.db` 檔案

### 手動還原
1. 關閉應用程式
2. 將備份的 `.db` 檔案覆蓋到：
   ```
   C:\Users\[您的使用者名稱]\AppData\Roaming\Spreadsheet Comparator\spreadsheet-comparator.db
   ```
3. 重新啟動應用程式

## ⚠️ 常見問題

### Q: 視窗開啟後顯示空白
A: 請稍等 5-10 秒，伺服器正在啟動。如果持續空白，請重新啟動應用程式。

### Q: 防毒軟體報毒
A: 這是誤報。Electron 應用程式常被誤報為病毒。您可以：
- 將應用程式加入防毒軟體的白名單
- 或暫時關閉防毒軟體進行安裝

### Q: 無法啟動
A: 請確認：
- Windows 10 或更新版本
- 64 位元作業系統
- 端口 3001 沒有被其他程式佔用

### Q: 資料遺失
A: 請檢查：
- 資料庫檔案是否存在（見「資料儲存位置」）
- 是否有備份可以還原

## 🆘 技術支援

如果遇到問題，請提供以下資訊：
- Windows 版本
- 錯誤訊息截圖
- 資料庫檔案大小

## 📝 系統需求

- **作業系統**: Windows 10/11 (64-bit)
- **記憶體**: 建議 4GB 以上
- **硬碟空間**: 1GB 以上
- **網路**: 不需要（完全離線運行）

## 🔧 解除安裝

1. 執行安裝目錄中的 `Uninstall Spreadsheet Comparator.exe`
2. 或透過「控制台」→「程式和功能」解除安裝

**注意**: 解除安裝不會刪除您的資料。如需完全移除，請手動刪除：
```
C:\Users\[您的使用者名稱]\AppData\Roaming\Spreadsheet Comparator\
```
